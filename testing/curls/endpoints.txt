* Curls for endpoints
** Create campaign
*** Parameters: <id> of the campaign in OML (in the URL) and "contact-strategy" in the Json POST
Example:
curl -d '{"contact-strategy": [1, 3, 4]}' -H "Content-Type: application/json" -X POST http://localhost:1440/create-campaign/4
** Edit campaign
*** Parameters: <id> of the campaign (in the URL) and "contact-strategy" in the Json POST
Example:
curl -d '{"contact-strategy": [1, 3]}' -H "Content-Type: application/json" -X POST http://localhost:1440/edit-campaign/4
** Start campaign

** Add disposition for incidence rule
*** Parameters: <id> of the campaign (in the URL), id of disposition option in OML <disposition_option> in OML and <id_contact>
Example:
curl -d '{"id_contact": 3, "disposition_option": 7}' -H "Content-Type: application/json" -X POST http://localhost:1440/add-incidence-rule-disposition/4
** Create incidence rule
*** <id> of the campaign (in the URL), id of the incidence rule <id_rule>, status <status>, <disposition_option_id>, name for the status <status_custom>, maximum number of attempts <max_attempt>, delay before attempt in seconds <retry_later>, mode (fixed o multi-number) <mode>
Example 1:
curl -d '{"id_rule": 3, "status": 3, "status_custom":"no answer", "max_attempt": 5, "retry_later": 5, "mode": 1, "type": 1}' -H "Content-Type: application/json" -X POST http://localhost:1440/create-incidence-rule/4
Example 2:
curl -d '{"id_rule": 4, "disposition_option_id": 7, "max_attempt": 5, "retry_later": 5, "mode": 1, "type": 2}' -H "Content-Type: application/json" -X POST http://localhost:1440/create-incidence-rule/4
** Update incidence rule
*** <id> of the campaign (in the URL), id of the incidence rule <id_rule>, status <status>, <disposition_option_id>, name for the status <status_custom>, maximum number of attempts <max_attempt>, delay before attempt in seconds <retry_later>, mode (fixed o multi-number) <mode>
Example 1:
curl -d '{"id_rule": 3, "status": 3, "status_custom":"no answer", "max_attempt": 5, "retry_later": 5, "mode": 1, "type": 1}' -H "Content-Type: application/json" -X POST http://localhost:1440/update-incidence-rule/4
Example 2:
curl -d '{"id_rule": 4, "disposition_option_id": 7, "max_attempt": 5, "retry_later": 5, "mode": 1, "type": 2}' -H "Content-Type: application/json" -X POST http://localhost:1440/update-incidence-rule/4
** Delete incidence rule
*** <id> of the campaign (in the URL), <id_rule> the id of the incidence rule in OML and OMD, <type> of the incidence rule
Example:
curl -d '{"id": 3, "type": 1}' -H "Content-Type: application/json" -X POST http://localhost:1440/delete-incidence-rule/4
** Add agenda for call
*** <id> of the campaign (in the URL), <campaign_name> name of the campaign in OML, <phone_number> to call, <datetime> the date and time selected to place the call
Example:
curl -d '{"id_contact": 7, "campaign_name": "clonan_33", "phone_number": "1231323, "datetime": "27/11/24 15:42:00"}' -H "Content-Type: application/json" -X POST http://localhost:1440/add-agenda/4
